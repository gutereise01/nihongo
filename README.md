# にほんご 연습장

JLPT N5~N1 단어·한자·문법·작문 연습 웹앱 (PWA).

- `index.html` — 공부 앱 (단어·한자·문법·작문·기록, 30일 계획)
- `kanji/` — 漢字 쓰기 노트 (상용한자 획순 연습)

사용법
- 아이폰: 사파리로 열고 공유 → **홈 화면에 추가**
- 한 번 열어 본 화면과 자료는 오프라인에서도 쓸 수 있어요.
- 학습 기록은 각자 기기(브라우저)에 저장돼요.
